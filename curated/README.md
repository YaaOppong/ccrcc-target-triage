# Curated layer

Everything in `results/` is generated by `code/pipeline.py`. **Nothing in this directory is.**

These files are authored or vendored inputs: hand-written interpretation, and API snapshots
taken through tooling the pipeline does not call. They are versioned here so the distinction
between *computed* and *curated* is visible in the directory structure rather than buried in a
comment — the previous layout mixed both under `results/`, which is how the repository drifted
out of sync with its own code.

| File | What it is | Consumed by the pipeline? |
|---|---|---|
| `clinical_agents.csv` | Held-out positive set for all 101 surface candidates. **Generated** by `pipeline.py` (Open Targets mechanism-of-action + ClinicalTrials.gov), but the `agent_modality` column is reserved for manual curation and is preserved across re-runs. | Yes — written and re-read |
| `celltype_specificity.csv` | HPA single-cell specificity for the shortlist, with a written `interpretation` per gene. | No |
| `trial_validation.csv` | Per-gene ccRCC trial evidence with hand-written summaries. | No |
| `anchor_trials.csv` | Detail on the CA9 and CD70 anchor trials. | No |
| `chembl_cache.json` | ChEMBL mechanism snapshot, retrieved via an MCP connector. Superseded by the Open Targets `drugAndClinicalCandidates` query the pipeline now runs; retained for provenance. | No |

## Why `agent_modality` is left blank

The recovery test's positive definitions are indication-based and fully mechanical, so they do
not depend on drug modality. A stricter *antigen-only* definition — restricting positives to
antibody / ADC / CAR agents and excluding small-molecule TKI targets such as MET, EGFR and FLT1 —
would be the fairer test of what this project actually claims to find, and would give a smaller,
more favourable denominator.

It is left uncurated because automated modality lookup is not trustworthy here: ChEMBL's text
search returns `Unknown` for both **MDX-1411** (anti-CD70 antibody) and **AGS-16C3F** (anti-ENPP3
ADC), which are exactly the calls that matter. Filling this column by hand, or from a source that
resolves ADCs correctly, is the single highest-value contribution to the evaluation.

If you fill it in, `pipeline.py` preserves your edits on re-run — it merges the existing column
back in by gene rather than overwriting the file wholesale.
